# Проверка безопасности — 31 октября 2026

## Исправления

- Вход и регистрация получили общие для всех процессов лимиты в БД. За 5 минут разрешены 10 запросов входа на пару email/IP, 50 запросов входа с IP и 10 регистраций с IP. Превышение возвращает `429` с `Retry-After`. При недоступности хранилища лимитов запрос отклоняется с `503`. Ключи счётчиков — HMAC, исходные email и IP не сохраняются. Параллельные запросы учитываются внутри транзакции.
- Клиентские заголовки IP не позволяют сбросить счётчики: `X-Forwarded-For` учитывается только за явно настроенным доверенным прокси. На Vercel используется перезаписываемый платформой заголовок `x-vercel-forwarded-for`.
- До разбора тела проверяется размер запроса: JSON API — 256 КиБ, формы авторизации — 64 КиБ, аватарки — 6 МиБ. Обработчик загрузки ограничивает суммарные данные файлов 5 МиБ, включая дополнительные файлы в multipart-запросе. Проверки типа, числа пикселей и перекодирование изображений сохранены.
- Production-конфигурация LiveKit требует WSS/HTTPS и секрет подписи длиной от 32 байт. URL с учётными данными, query или fragment отклоняется. Управляющие HTTP-запросы не следуют перенаправлениям, чтобы административный bearer-токен не ушёл на другой адрес. Локальный WS/HTTP разрешён в debug-режиме.
- Vite обновлён до `8.1.6`, source-map-js — до `1.2.2`; lock-файл обновлён вместе с зависимостями сборщика.

## Проверенные ограничения доступа

Проверки владельца события уже выполнялись на сервере. Дополнительные регрессионные проверки подтверждают отказ чужому организатору при изменении и удалении события, публикации, переносе, изменении требований к анкете, аудиторий и программы, чтении списков участников, проверке QR и управлении трансляцией. Проверяется отсутствие изменений в БД и утечки email участника в ответах.

Также проверены анонимный доступ, CSRF, невозможность повысить привилегии полями JSON, изоляция персональных уведомлений и QR, одноразовая отметка посещения, права участников видеокомнат. Для лимитов входа есть проверка 20 одновременных запросов: допустимое число попыток не превышается.

## Зависимости и границы проверки

Список зависимостей не отправлялся в сервисы аудита. Публичные выгрузки OSV для PyPI и npm скачаны целиком; версии из обоих lock-файлов сопоставлены с диапазонами уязвимых версий локально. После обновления совпадений не осталось (13 пакетов PyPI и 184 пакета npm; 26 775 и 230 993 записи базы соответственно). Проверка известных уязвимостей не заменяет анализ кода и не доказывает отсутствие неизвестных проблем.

На отдельной копии итогового набора изменений прошли 384 теста бэкенда, 151 UI-тест, тесты библиотек фронтенда, проверка TypeScript и production-сборка. `makemigrations --check --dry-run` не обнаружил расхождений; `check --deploy` не сообщил проблем.

Автоматические тесты выполнялись на SQLite. PostgreSQL и конфигурация работающего production-сервера в этой проверке не тестировались.

## Выкладка

Примените миграции обычным `migrate`. Для собственного reverse proxy задайте `DJANGO_TRUSTED_PROXY_IPS`; у Caddy на той же VM это `127.0.0.1/32,::1/128`. Новая установка через bootstrap задаёт эти адреса автоматически. Проверьте, что публичный LiveKit использует WSS/HTTPS и случайный секрет от 32 байт. Изменения не требуют изменения пользовательских паролей.
