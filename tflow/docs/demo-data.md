# Данные для защиты

Набор содержит 10 участников, 2 организаторов, 10 опубликованных событий, 1 черновик, 30 активностей и 4 клуба. Даты рассчитываются от момента загрузки: онлайн-студия уже идёт, остальные события запланированы вперёд; одно мероприятие завершено и имеет отметки посещения.

## Вход на сервере

| Роль | Email | Пароль |
|---|---|---|
| Основной организатор | `test@jury.example.test` | `test` |
| Другой организатор | `other@jury.example.test` | `test` |
| Участник 1 | `1@jury.example.test` | `1` |
| Остальные участники | `2@jury.example.test` … `10@jury.example.test` | Соответственно `2` … `10` |

На сервере вводится полный email. Короткие локальные логины не включаются в production.
Grafana доступна основному организатору `test@jury.example.test` после обычного входа на сайте: `/grafana/d/tflow-production/tflow`.

## Готовые сценарии

- «Открытая студия: нейросети в работе»: текущий онлайн-флоу, билеты всех участников, старт эфира без ожидания будущей даты.
- «Запусти свой первый продукт»: гибридное событие с параллельными очным и онлайн-флоу; запуск будущего эфира ограничен расписанием.
- «Дизайн понятных интерфейсов»: перед записью требуются телефон и организация.
- «Python: от скрипта к приложению»: три билета, очередь мероприятия и отдельная очередь на заполненную активность.
- «Движение и энергия»: прошедшее мероприятие с подтверждённым посещением участников 8–10.
- «Город в объективе»: принадлежит второму организатору; основной организатор не может его изменять.
- «Робототехника: собираем первый прототип»: черновик для демонстрации подготовки и публикации.

## Однократная подготовка

Подтверждённый запрос `defense-2026-11-01-all-accounts` применяется штатной выкладкой на vm1 один раз: данные и аккаунты заменяются транзакционно, без резервной копии по указанию владельца. Выполненный запрос отмечается вне пользовательской БД в `/var/lib/tflow/maintenance`. Последующие выкладки не очищают и не перезаполняют данные.

Локальная ручная команда для явно разрешённой полной замены настроенной БД:

```sh
python manage.py prepare_defense --reset-all --yes
```
