# Точечное обновление вебинаров

Перенесены HTTPS-трансляции, отдельная студия, восстановление текущего эфира,
серверный чат, ссылки лекторам и запуск по времени из `main` (`2a6c050`),
а также создание онлайн-потока рядом с очными аудиториями из `1f4ef56`.
Остальные изменения этих веток не входят в перенос. Настройки почты и текущий
интерфейс флоу сохранены.

Миграция `0022_webinar_updates` зависит от существующей цепочки `gosha` и
добавляет таблицы трансляций, чата, ссылок и посещений активностей без удаления
данных. Перед обновлением рабочей базы нужна резервная копия.

## Выбор транспорта

По умолчанию остаётся LiveKit. Для HTTPS-режима нужен постоянный сервер с FFmpeg
(H.264/AAC) и общий каталог для Django и обработчика видео:

```sh
export TFLOW_HTTP_BROADCAST=1
export TFLOW_FFMPEG=/path/to/ffmpeg
python backend/manage.py migrate
npm run dev
```

`dev.mjs` запускает обработчик автоматически. В production нужно отдельно
запустить `python manage.py run_broadcast_worker` из каталога `backend`,
с теми же настройками и базой, что у Django. Шаблон ограниченной systemd-службы
находится в `deploy/spirit/broadcast_service.py`; сам перенос не устанавливает
службу и не меняет окружение production. Каталог `TFLOW_HTTP_BROADCAST_ROOT`
должен быть доступен обоим процессам, приватен и находиться на постоянном диске.
На Vercel этот транспорт отключён: ему нужен постоянный процесс кодирования.

Видео поступает авторизованными HTTP-запросами и воспроизводится через HLS.js
или встроенный HLS в Safari. Обработчик ограничен двумя одновременными эфирами,
размер входного фрагмента — 2 МБ. Открывать публичные медиапорты не требуется.
Для реальной камеры и микрофона нужен HTTPS; localhost пригоден для разработки.

## Студия и чат

У каждого онлайн-пункта программы своя студия и ссылка лектора. После обновления
студии ведущий нажимает «Восстановить трансляцию» и включает устройства заново:
сессия и чат сохраняются. Завершение эфира требует подтверждения. Ссылку лектора
можно обновить или отозвать без смены роли его аккаунта.

Автор сообщения — часть почты до `@`, вычисленная по аккаунту на сервере.
Клиент не может подставить произвольного автора. Домен почты в подпись не входит.
Enter отправляет сообщение, Shift+Enter добавляет строку.

## Проверка переноса

Проверены серверные права, отзыв ссылок, расписание, загрузка и декодирование
реальных H.264/AAC-сегментов, сохранение сессии и старый режим LiveKit.
В Chromium с искусственными камерой и микрофоном проверены передача видео
960×540, чат между двумя аккаунтами с пустыми именами профиля, восстановление
студии и завершение у зрителя. Нагрузочная проверка и реальные устройства в этот
перенос не входят.
