# Проверка ТФлоу

Проверено 30 октября 2026 года на macOS, в локальных Vinext и собранном Worker с постоянной D1.

- `npm run check` — успешно.
- `node <sites-plugin>/scripts/build-site.mjs` — production build успешно.
- `npm run db:migrate:local` — обе миграции применены, повторный запуск их пропускает.
- `npm run test:api -- http://127.0.0.1:4174` — 68 проверок, успешно.
- 20 конкурентных запросов к последнему месту: 1 успешный, 19 отклонены с `NO_SEATS`.
- Два одновременных запроса одного пользователя на пересекающиеся активности: одна запись, один `PARTICIPANT_CONFLICT`.
- Перенос с конфликтом участника и наложение аудиторий отклоняются без изменения состояния.
- Проверены HTTP 401/403, недоступность чужих черновиков и списков участников, невозможность отменить чужую регистрацию.
- Проверены сохранение профиля, избранное, уведомление после переноса и актуальность личного расписания.

## Браузер

Chromium, 1440×1040 и 390×844. Нет JavaScript-ошибок и горизонтального переполнения. Проверены поиск, фильтр по теме, запись, блокировка временного пересечения, отображение в расписании, отмена записи, мобильная навигация, открытие диалога и закрытие по Escape.

Отдельно из интерфейса созданы мероприятие, две аудитории (40 и 20 мест), активность; программа опубликована и доступна на странице события. Рабочие записи получены из API/D1, не из заглушки frontend.

## Границы

Нагрузочная проверка ограничена 20 конкурентными регистрациями, а не полноценным стресс-тестом. Учебные данные и тестовые регистрации намеренно отделены от миграций и хранятся только в базе среды выполнения. Вход в опубликованную версию требует аккаунт ChatGPT и доступа владельца к приватному Site. Дополнительные механики ТЗ (лист ожидания, QR, автоматическое распределение) в этот MVP не входят.
