# Проверка Django-версии ТФлоу

30 октября 2026, macOS, Python 3.12, Django 5.2.18, React/Vite.

## Backend

- `python backend/manage.py check` — без ошибок.
- `python backend/manage.py makemigrations --check --dry-run` — нет неприменённых изменений схемы.
- `check --deploy` с production-настройками — без предупреждений.
- `python backend/manage.py test flow.tests --noinput` — 31 тест успешно.
- 20 конкурентных запросов к последнему месту: одна запись, 19 ответов `NO_SEATS`.
- Две одновременные записи одного пользователя на пересекающиеся активности: одна запись, один `PARTICIPANT_CONFLICT`.
- Проверены роли владельца события, скрытие черновиков, запрет чтения чужих контактов, изоляция отмены и уведомлений.
- Проверены CSRF для входа и API, запрет cross-origin изменения, хеширование паролей, сессия/выход и игнорирование старых identity-заголовков.
- Проверены границы дат, вместимость, аудитории других событий, соседние интервалы и откат невалидного переноса.

## Frontend

- `npm run check` — TypeScript успешно.
- `npm run build` — production bundle успешно.
- 162 браузерные проверки переполнения: 9 разделов × 18 ширин (280, 320, 360, 390, 430, 520, 640, 768, 820, 900, 960, 1024, 1140, 1280, 1440, 1536, 1920, 2560 px). Переполнения документа, шапки, поиска, карточек и активностей нет. JavaScript-ошибок нет.
- Через настоящие Django-формы создан тестовый аккаунт. Проверены запись, блокировка пересечения, расписание после перезагрузки, отмена, создание события и двух аудиторий, добавление активности, публикация и выход POST-запросом.
- Собранное приложение запущено через Gunicorn с двумя Python worker-процессами: главная, API, форма входа, JS, CSS и шрифт возвращают HTTP 200 без Node runtime. В этой локальной проверке HTTPS redirect отключён только для loopback HTTP-порта.

## Перенос данных

Из прежней локальной D1 импортированы 48 профилей (включая тестовые), 9 событий, 18 аудиторий, 27 активностей, 4 регистрации, 4 сообщества и 2 уведомления. Повторный импорт не дублирует и не перезаписывает строки. Исходная D1 сохранена; согласованные снимки находятся в игнорируемой папке backend/data/backups.

## Границы проверки

SQLite и локальные HTTP-сценарии проверены. Поддержка PostgreSQL подготовлена, реальная PostgreSQL в этой сессии не запускалась. Dockerfile подготовлен, сборка контейнера не запускалась. Новая версия не развёрнута в старом ChatGPT Sites: теперь приложению нужен Python/Docker-хостинг.
