# Правила работы с Git

- Перед коммитом и пушем обновляйте текущую ветку из её удалённой ветки. До pull сохраните незакоммиченные изменения; не теряйте чужую локальную работу.
- При конфликтах объединяйте изменения так, чтобы сохранялись новые функции других участников репозитория и текущая реализуемая функция. Не заменяйте целые файлы через `ours` или `theirs`, если это удаляет нужные изменения.
- Актуальная версия формы регистрации — в `origin/main`. При синхронизации не возвращайте её к старому варианту. Менять её поведение или оформление можно по отдельному запросу пользователя.
- В коммит включайте изменения текущей задачи. Несвязанные незавершённые изменения других участников сохраняйте в рабочем каталоге.
