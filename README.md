# ТФлоу

Сайт: https://tflow-one.vercel.app/ · GitLab: https://gitlab.t-education.com/hack-mmk-25/tflow/-/tree/main

Платформа мероприятий по ТЗ EventFlow в жёлто-белом стиле референса Т Банка. Backend полностью на Python/Django, интерфейс — React/TypeScript. Каталог, программа, аудитории, регистрация на активности, личное расписание, кабинет организатора, сообщества и избранное.

## Быстрый запуск

Нужны Node.js 22.13+, Python 3.11+ и npm. Если установлен [uv](https://docs.astral.sh/uv/), настройка автоматически создаст Python 3.12 environment.

```bash
cd tflow
npm ci
npm run setup
npm run dev
```

Открыть **http://127.0.0.1:5173/**. API работает на Django: `http://127.0.0.1:8000/api/health`.

Создайте аккаунт через «Войти → Зарегистрироваться» и выберите роль. Пользователи входят по почте и паролю; пароли хешируются Django, запросы защищены CSRF, сессия хранится в HttpOnly cookie. Демо-входы и шаблонные мероприятия удалены.

`npm run setup` применяет миграции без наполнения базы. Старые данные автоматически не импортируются. Локальные данные и секреты не попадают в Git.

## Проверки

```bash
cd tflow
npm run check
npm run build
npm run test:backend
```

126 Django-тестов: права, сессии, CSRF, пересечения, вместимость, отмена, переносы, избранное, профиль, QR, импорт и очистка данных. Дополнительно проверяются некорректный JSON, типы и Unicode, изоляция личных данных, ограничения базы, миграции и настройки production. Отдельные конкурентные тесты проверяют 20 попыток занять последнее место, одновременные сканы QR и две одновременные записи одного человека на пересекающиеся активности.

Верстка проверена в браузере на 14 ширинах от 280 до 2560 px в одиннадцати экранах двух ролей; дополнительно проверена форма создания на трёх ширинах (157 проверок). Сетки, поиск и кнопки перестраиваются по доступной ширине; меню сворачивается до появления переполнения. Таблица участников прокручивается внутри своего контейнера.

## Запуск собранного приложения без Node-сервера

```bash
cd tflow
npm run build
# Backend, шаблоны входа и собранный frontend обслуживает один Django:
npm start
```

Адрес: `http://127.0.0.1:5173/`. Для production используется Gunicorn/WSGI, а не `runserver`. Подробности и Docker — в [tflow/README.md](./tflow/README.md).

Актуальный сайт: **https://tflow-one.vercel.app/** — Django на Vercel с постоянным PostgreSQL Neon. Историческая публикация ChatGPT Sites содержит старую Worker-версию 0.1.

## Две роли и вход по QR

- **Участник:** каталог, большая кнопка регистрации на событие, билеты и один личный QR в профиле. Запись на активности — дополнительная возможность внутри программы.
- **Организатор:** собственные события, создание короткой формой, перенос времени/площадки, список зарегистрированных и вошедших. У каждого события свой сканер.
- Сканер принимает человека только при наличии регистрации именно на выбранное событие. Повторный скан показывает существующую отметку и не увеличивает счётчик.
- QR содержит непрозрачный случайный идентификатор. Личные данные доступны самому участнику и организатору события, на которое тот зарегистрирован.

Обычная регистрация предлагает выбрать роль. Участник может открыть «Профиль → Стать организатором» или раздел организатора в верхнем меню и включить создание событий в своём аккаунте. Билеты, расписание, личный QR и текущая сессия сохраняются; права Django-администратора не выдаются. В кабинете: «Создать событие → Создать черновик → Опубликовать». Через «Участвовать» можно вернуться в каталог и записываться на чужие события. Прежние владельцы событий автоматически получили роль организатора при миграции.

Камера использует заднюю камеру телефона и требует HTTPS либо localhost; фотографию QR можно загрузить отдельно. На реальном телефоне нужен доступный ему HTTPS-адрес приложения. Физическая камера телефона в текущей сессии не использовалась: проверены настоящий PNG-код и видеодекодер на синтетическом MediaStream.

## Vercel и пустая база

Настройки публикации находятся в `tflow/vercel.json`; корень проекта Vercel — `tflow`, framework — Django. Нужны секрет `DJANGO_SECRET_KEY` и постоянный PostgreSQL `DATABASE_URL` с TLS. Сборка компилирует React и применяет миграции; страницы и API обслуживает Django, собранные ресурсы публикуются под `/static/app/`. Демо-наполнение отсутствует, повторный деплой сохраняет пользовательские данные.

Для явно запрошенной очистки настроенной базы: `cd tflow && .venv/bin/python manage.py reset_data --yes`. Команда удаляет пользователей, мероприятия, билеты, входы, сообщества и сессии. Схема и служебная блокировка расписания сохраняются.
