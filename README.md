# ТФлоу

Адаптивная платформа мероприятий по ТЗ EventFlow: каталог, программа, аудитории, регистрация на активности, личное расписание и кабинет организатора. Жёлто-белый интерфейс по референсу Т Банка, без рекламных баннеров.

Приложение находится в [`tflow/`](./tflow). Все пользовательские записи хранятся на сервере в Cloudflare D1. Репозиторий: `DertyuGameDev/ProdMurm2026`.

Приватная опубликованная версия: [Открыть ТФлоу](https://tflow-prod-murm-2026.sidovidchenko.chatgpt.site). Доступ через аккаунт владельца ChatGPT. Каталог учебных событий создаётся при первом входе. Production API и подключение D1 проверены; полный вход владельца выполняется в его браузере.

## Локальный запуск

Node.js 22.13+ (для помощника миграции — 22.13+ с `node:sqlite`), npm и Git.

```bash
cd tflow
npm ci
npm run build
npm run db:migrate:local
npm run dev
```

Открыть адрес из вывода сервера (обычно `http://127.0.0.1:5173`). Кнопка «Войти» в локальной разработке использует тестового пользователя Sites. После первого входа создаются шесть учебных мероприятий с двумя аудиториями и тремя активностями в каждом. После перезапуска данные сохраняются в `.wrangler/state`.

В опубликованном приложении вход выполняется через Sign in with ChatGPT. Проверку личности обеспечивает Sites. Любой вошедший участник может создать собственное мероприятие; управлять чужой программой нельзя.

## Проверки

```bash
cd tflow
npm run check
npm run build
npm run db:migrate:local
npm run start -- --port 4174
# В другом терминале:
npm run test:api -- http://127.0.0.1:4174
```

API-тест предназначен только для локального собранного Worker. Он создаёт отдельные тестовые аккаунты и событие, проверяет права, пересечения, дубли, отмену, сохранение профиля и 20 конкурентных попыток занять последнее место. Тестовые записи остаются в локальной базе. Для демонстрации через браузер предпочтителен `npm run dev`: он поддерживает локальный вход. Не публикуйте прямой Worker вне Sites dispatch без реализации проверенной авторизации.

Подробности архитектуры и матрица требований: [`tflow/docs/requirements.md`](./tflow/docs/requirements.md). Дополнительные функции ТЗ — лист ожидания, QR-посещаемость и автоматическое распределение — не включены в MVP.
